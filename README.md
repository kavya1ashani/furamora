# Furamora – Pet Care Platform

A web-based application connecting pet owners and dog walkers.

## Features
- User authentication (Firebase)
- Booking system
- Walker dashboard
- Owner dashboard
- Admin dashboard
- Walk reports
- Real-time location tracking during walks

## Technologies
- HTML, CSS, JavaScript
- Firebase (Authentication & Firestore)
- Browser Geolocation API
- Google Maps JavaScript API
- GitHub Pages (hosting)
